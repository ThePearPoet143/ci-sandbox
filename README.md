# ci-sandbox

A test repo where ci's stories are walked through on real pull requests
(Linear: "Plan: ci per repo, proven on a sandbox"). It calls ci at one release and holds a little product code, a
script and its test, so product changes and rule changes can both be tried.

The first commit went straight to `main`, before the repo had a rule set.

Opened by an agent on sushihome-2, with ci’s rules.
